# Erdős Problem #973

**Status:** Substantive numerical narrowing of a constant.

On Turán's polynomial-iterate constant $C$ governing $\max_{2 \le k \le n+1} \left|\sum_{i=1}^n z_i^k\right|$ for sequences with $|z_i| \ge 1$:

- Prior best: $C < 2e \approx 5.44$ (Turán's Theorem 6.1, [Tu84b]; noted in Tang's comment on the problem page).
- New: $C < 1.06157$.

**This is a tightening, not a closure** — the underlying question of whether a constant $C > 1$ exists at all remains open. A manuscript has not yet been compiled from the working notes.
